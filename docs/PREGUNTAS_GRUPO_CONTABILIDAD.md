# Preguntas para el Grupo de Contabilidad

1. ¿Qué información necesitan recibir de nuestra Pasarela de Pagos?
2. ¿Qué historias de usuario desarrollaron?
3. ¿Qué tecnologías utilizan?
4. ¿Tienen APIs funcionando y cuáles son sus rutas?
5. ¿Qué identificador utilizan para los pedidos?
6. ¿Cómo registran pagos aprobados y rechazados?
7. ¿Cómo manejarán pagos contra entrega pendientes?
8. ¿Cómo manejarán anticipos y saldos pendientes?
9. ¿Necesitan consultar una transacción o recibir una notificación?
10. ¿Cómo evitarán registrar dos veces el mismo pago?
11. ¿Qué datos necesitan para las primeras pruebas locales?
12. ¿Quién coordinará las pruebas entre los dos grupos?
13. ¿Qué respuesta debe devolver Contabilidad después de registrar un movimiento?
14. ¿Cómo identificaremos que los datos son una simulación académica?
15. ¿Registrarán intentos rechazados o solo dinero recibido?
16. ¿Qué debe ocurrir cuando el estado no puede confirmarse?
17. ¿Cómo se confirmará posteriormente el recaudo contra entrega?
18. ¿Qué autenticación usaremos entre módulos?
19. ¿Qué campos consideran sensibles y quién puede consultarlos?
20. ¿Cómo versionaremos el contrato de integración?

No se debe programar la integración hasta acordar campos, estados, seguridad,
duplicados y responsabilidades de cada grupo.
